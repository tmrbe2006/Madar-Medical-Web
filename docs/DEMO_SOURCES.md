# مصادر أسماء القوائم التجريبية

تمت مراجعة أسماء شركات التأمين من مواقعها، واستخدمت أسماء علمية شائعة للأدوية ضمن مراجع قوائم الأدوية. أسماء الفحوص والتخصصات تسميات طبية عامة. هذه مراجع للأسماء فقط؛ لا تثبت أسعارًا أو نسب تحمل أو شبكة تعاقد للمنشأة ولا تشكل توصية بالجرعات.

- قائمة الأدوية الأساسية بمنظمة الصحة العالمية: https://www.who.int/publications/i/item/B09474
- قائمة الأدوية الأساسية لمصر 2025: https://www.who.int/publications/m/item/egypt--national-essential-medicine-list-2025-%28english%29
- أكسا مصر — التأمين الطبي المحلي: https://www.axa-egypt.com/ar/web/axa-eg/individual-local-health
- أليانز مصر — التأمين الطبي: https://www.allianz.com.eg/ar/individual-solutions/health-insurance/health-insurance
- مصر للتأمين — التأمين الطبي: https://misrins.com.eg/ar/التغطيات-التأمينية/أنواع-التأمين/221-التأمين-الطبي

أسماء المرضى والأطباء مركبة لغرض المحاكاة، والهواتف أصفار، ولا تمثل بيانات أشخاص حقيقيين. أسعار الخدمات والتحمل ونسب الأطباء أمثلة. لا توجد وصفة علاجية تلقائية؛ الطبيب يحدد محتوى الروشتة بنفسه.
